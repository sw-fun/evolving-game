# Asks for agentrail

What this repository needs from agentrail
(https://github.com/sw-vibe-coding/agentrail-rs). Not fixed from
here; each ask names what was done meanwhile.

## 1. The generated briefing should be ASCII only

Status: open (2026-11-15). Kind: output format.

What: `agentrail instructions apply` (profile `default`, version
`ccec47f9fba16062`, agentrail 0.1.0 at e3b2747) writes a block into
`CLAUDE.md` / `AGENTS.md` that contains em dashes (U+2014): 34 of
them, for example in the marker comment
(`AUTOGENERATED BY ... apply` followed by an em dash and
`DO NOT EDIT BY HAND`) and in the step headings (`### 1. START`
followed by an em dash).

Why: the repositories that use agentrail keep their markdown ASCII
only and check it with `sw-markdown-checker`. A file holding the
briefing fails that check through no text of its own, so each
repository has to exclude it, and then its own instructions in the
same file go unchecked.

Repro:

```bash
agentrail instructions apply
sw-markdown-checker -f "CLAUDE.md"    # fails: Non-ASCII character U+2014
```

Asked: write the embedded fragments (`agent-instructions/`) in ASCII:
` -- ` or a colon where an em dash is now. A test in agentrail that
the rendered briefing is ASCII would keep it so.

Meanwhile: this repository's gate runs `sw-markdown-checker` on
`README.md` and `docs/*.md`, not on `CLAUDE.md` or `AGENTS.md`.
